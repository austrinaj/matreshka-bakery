# Матрёшка: сайт + CRM + Telegram-бот

Шаблонный проект для пекарни. Пока это черновик, не боевая версия.

## Что внутри

| Файл | Что делает |
|---|---|
| `app.py` | Сайт на Flask: меню, форма заказа, CRM по адресу `/admin`, приём сообщений бота |
| `bot.py` | Логика Telegram-бота: заказы, смена статусов кнопками, статистика |
| `tg.py` | Запросы к Telegram Bot API и уведомления о новых заказах |
| `set_webhook.py` | Один раз подключает бота к сайту на хостинге |
| `db.py` | Работа с базой SQLite (`bakery.db`), общей для сайта и бота |
| `templates/` | HTML-страницы |
| `static/style.css` | Стили |

## Как запустить у себя

1. Скопировать `.env.example` в `.env` и заполнить его.
2. Установить зависимости (один раз):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустить сайт: `python app.py`, затем открыть http://localhost:5000
4. Во втором терминале запустить бота: `python bot.py`

Внимание: локальный `bot.py` отключает бота на хостинге. Чтобы вернуть его,
снова выполни на хостинге `set_webhook.py`.

CRM: http://localhost:5000/admin, пароль берётся из `ADMIN_PASSWORD`.

## Как это работает на хостинге (PythonAnywhere)

Там отдельный `bot.py` не запускается. Telegram сам присылает сообщения боту
на адрес `/tg-webhook` нашего сайта (это называется вебхук), поэтому
сайт и бот работают как одна программа.

## Команды бота

- `/orders`: активные заказы с кнопками статусов
- `/all`: последние 10 заказов
- `/order 5`: показать заказ №5
- `/today`: число заказов и выручка за сегодня
- `/menu`: текущее меню
